## Chess pieces

The 12 piece sprites are rasterized from the standard Unicode chess symbols
(U+2654–U+265F) and then recolored/outlined for this plugin. No font file is
redistributed.

## Chess You reference

The installed Chess You Demo was used only as a visual reference for pixel
density, outline weight, expression vocabulary and panel framing. No asset from
that game is bundled or redistributed.
